# 🧠 Project Constitution  
**Project Name:** In-Memory Todo CLI Application  
**Model:** Qwen  
**Development Method:** Agentic Dev Stack with Spec-Kit Plus  

---

## 1. Purpose

This project builds a Python-based command-line Todo application that stores all tasks in memory.  
The primary goal is to demonstrate **spec-driven, agentic software development** rather than manual coding.

All development must be driven by specifications, plans, and task breakdowns generated and executed by the AI agent.

---

## 2. Core Development Rules

1. **Spec-First Workflow**
   - No code may be written before a specification exists.
   - All behavior must originate from `sp.spec`.

2. **No Manual Coding**
   - The human may only provide prompts, feedback, and approvals.
   - All Python code must be generated by Qwen.

3. **Mandatory Development Phases**
   Development must strictly follow this order:
   1. `sp.spec` – Define features, constraints, and behavior
   2. `sp.plan` – Generate an implementation plan
   3. `sp.tasks` – Break the plan into atomic tasks
   4. Implementation – Execute tasks incrementally

4. **Agent Discipline**
   - Never skip phases
   - Never implement features not defined in the spec
   - Ask for clarification only if requirements are ambiguous

---

## 3. Functional Requirements

The application must implement **all five basic Todo features**:

1. Add Task  
2. View Tasks  
3. Update Task  
4. Delete Task  
5. Mark Task as Complete  

Each task must:
- Have a unique ID
- Store a title
- Maintain a completion status (Pending / Completed)

All data must exist **only in memory**.

---

## 4. Non-Functional Requirements

- Clean, readable, and maintainable Python code
- Proper separation of concerns
- Modular project structure
- Graceful handling of invalid user input
- Simple menu-driven CLI interface
- No persistence beyond program execution

---

## 5. Technology Constraints

The implementation must strictly use:

- Python 3.13+
- UV for environment and dependency management
- Spec-Kit Plus for spec-driven development
- Qwen as the code-generating agent


---

## 6. Agent Behavior Guidelines (Qwen)

When acting as the development agent, Qwen must:

- Follow the current Spec-Kit Plus phase exactly
- Generate production-quality Python code
- Keep logic simple and explicit
- Prefer clarity over cleverness
- Refactor or improve code when requested
- Clearly indicate phase transitions
